# Food Calorie Counter

## About
The **Food Calorie Counter** is a web-based application that helps users monitor their daily calorie intake and burned calories. This tool is designed to assist users in maintaining a balanced diet and tracking their fitness progress.

## Features
✅ Set a **daily calorie goal**
✅ Add and track **food items** with calorie values
✅ Log **exercise activities** to calculate burned calories
✅ **Real-time calorie balance**: See surplus or deficit
✅ **User-friendly** dark mode interface

## Tech Stack
- **HTML** – Structuring the page
- **CSS** – Styling with a modern blue theme
- **JavaScript** – Interactive calculations and UI updates

## Getting Started
### Installation
1. Clone this repository:
   ```sh
   git clone https://github.com/SaiBalaji2886/food_calorie_counter
   ```
2. Navigate to the project folder:
   ```sh
   cd food_calorie_counter
   ```
3. Open `index.html` in a web browser.

### How to Use
1. **Enter your daily calorie budget**.
2. **Add meals/snacks** with their respective calorie values.
3. **Log exercises** to subtract burned calories.
4. Click **Calculate** to see the remaining calories.
5. Identify whether you have a **Calorie Surplus** or **Deficit**.
